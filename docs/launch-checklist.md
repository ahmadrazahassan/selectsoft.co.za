# Launch checklist

* Verify every seeded product fact, source, score and editorial date
* Confirm permission for every official logo and product screenshot
* Replace preview author records with verified editorial profiles
* Review the methodology, editorial policy and commercial disclosure
* Arrange South African legal review for privacy, consent, retention and terms
* Create the production Supabase project and run the migration and seed
* Create the first approved admin profile and disable public registration
* Configure secure environment values and allowed auth redirect addresses
* Test newsletter, contact and editorial sign in flows
* Review storage policy, backups and recovery
* Validate the sitemap, robot rules, RSS and share image
* Complete keyboard, screen reader, mobile and browser checks
* Run performance and security reviews
